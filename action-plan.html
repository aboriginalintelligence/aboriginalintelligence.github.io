One plan

Start with the things that create a record

01

Read the source code

Download the 2014 customary regulations and the accountability by-law. Read the actual pages before relying on summaries.

02

Mark the gaps

Write down every section that is unclear, outdated, hard to enforce, or silent about authority, records, accountability, or member participation.

03

Compare the proposed documents

Use the proposed governance documents as working drafts. Keep what improves clarity and reject anything that does not protect members.

04

Request the amendment record

Ask for the current adopted version, all amendments, related resolutions, and the process for changing the code.

05

Build member support

Discuss the gaps with other members. Keep the conversation focused on rules, evidence, and workable improvements, not personalities.

06

Demand a public process

Support plain-language drafts, a transparent review period, recorded feedback, member approval, and a final code that is easy to find.

07

Get independent advice

Where a rule is unclear or the consequences are serious, ask an independent governance or legal professional to explain the options.

Templates

Letter 1. Request the rules and records

I am requesting copies of the current governance rules and any amendments or resolutions that change them.

Please provide:

1. The 2014 Customary Election Regulations and any amendments.
2. The Council Accountability and Procedures By-law and any amendments.
3. A current list of governance policies and procedures.
4. The process for members to propose, review, and approve changes.
5. The public record of decisions made under these rules.

Please explain how members can review these materials and participate in the process of improving the code.

Templates

Letter 2. Request a public code review

I am asking for a transparent member process to review and improve the governance code.

The process should identify unclear rules, publish proposed amendments in plain language, allow members to ask questions, record the feedback received, and make the final approved code available to everyone.

The goal is not to blame anyone. The goal is a clear, current, enforceable code that applies consistently and prevents the same governance problems from repeating.

Keep it peaceful and factual

What not to do

  • Do not turn a governance problem into a personal attack. Keep the focus on rules and records.
  • Do not claim a public proposal is already law. Identify what is adopted and what is still proposed.
  • Do not circulate altered documents as if they were the source. Keep the original code available for comparison.
  • Do not threaten staff or community members. A stronger code requires a process people can trust.
