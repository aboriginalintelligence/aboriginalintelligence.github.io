The governance gap

The rules are the issue

This page is not about personalities or blame. It is about whether the rules are clear enough to protect members, guide decision-makers, and prevent the same failures from repeating.

Open the action plan Read the 2014 code

What is good about the 2014 code

A written baseline is better than unwritten power

The 2014 customary regulations put procedures in writing. That gives members something they can read, compare, question, and improve.

The documents organize responsibilities, process, records, meetings, and member participation. A written framework can make decisions more consistent and make accountability possible.

The 2014 accountability by-law also recognizes that council work needs defined procedures, records, and standards of conduct. Those are useful foundations for a stronger governance system.

What needs to be better

A code must close the gaps it creates

A dated code may not answer every modern governance question. Members need clear language about authority, vacancies, transitions, conflicts, records, public reporting, complaints, appeals, and enforcement.

If a rule can be read two different ways, the people affected by the decision carry the risk. If a process is not public, members cannot verify whether it was followed.

The source scans include original and review markings. Preserve them as the historical record, but do not confuse a source document with a complete, current, member-approved governance system.

The standard

Clear rules. Public records. Member control.

A stronger code should be easy to find, written in plain language, approved through a transparent member process, and strong enough to apply to everyone. It should say who decides, how decisions are recorded, how members can challenge a decision, and what happens when the rules are not followed.
